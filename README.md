# Module 2 – Data Analysis with Python

This repository contains my work for **Module 2: Data Analysis with Python** as part of my internship training.

##  Module Overview

In this module, I worked with a real-world online retail dataset and performed data cleaning, preprocessing, feature engineering, and exploratory data analysis using Python.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Jupyter Notebook

## Dataset

The project uses an Online Retail dataset containing transaction-level information such as:

- Invoice
- Stock Code
- Product Description
- Quantity
- Invoice Date
- Price
- Customer ID
- Country

## Work Completed

### 1. Data Loading
- Imported the dataset using Pandas
- Examined dataset dimensions and columns
- Inspected the first few records

### 2. Data Cleaning
- Identified missing values
- Removed invalid records
- Handled missing Customer IDs
- Removed duplicate records
- Checked data types

### 3. Feature Engineering
Created additional analytical features:

- Revenue
- Year
- Month
- Month Name
- Day Name
- Hour

### 4. Data Validation
- Checked missing values
- Verified duplicate records
- Validated revenue calculations
- Checked the final dataset structure

### 5. Exploratory Data Analysis
Analyzed important business questions such as:

- Monthly sales trends
- Revenue by country
- Top-selling products
- Customer purchasing behavior
- Order quantity patterns
